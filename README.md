# The Brain Replays 2014

A one-line patch note for a bug in real life: the brain replaying an embarrassing moment from 2014 whenever the user tries to sleep.

## The text

v3.1.0: fixed a bug where the brain replayed an embarrassing moment from 2014 every time the user tried to sleep.

## How to run

Python 3.13, standard library only, no network.

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
